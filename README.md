# Stock Market Data Analysis

This project evaluates the historical stock performance of Apple (AAPL), Microsoft (MSFT), Nvidia (NVDA) and JPMorgan Chase (JPM) using Python.

## Analysis

The project analyzes:

- Historical stock prices
- Daily returns
- Cumulative returns
- Annualized volatility
- Correlation between stocks

## Technologies Utilized

  - Python
  - pandas
  - NumPy
  - Matplotlib
  - yfinance
  - Google Colab
 
## Key Findings
 
  - Among the four stocks, Nvidia displayed the highest average daily return.
  - The stock that experienced significantly higher volatility was Nvidia.
  - Microsoft showcased moderately strong correlations with both Apple and Nvidia.
  - JPMorgan Chase demonstrated weaker correlations when compared to the other three technology stocks.
